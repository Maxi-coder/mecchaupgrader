# 🚀 Meccha Upgrader

This is a handy utility can make sure that you no longer have to worry about being found in the game.

Here you will find everything needed for the project to work. Follow the simple instructions below to download the files and properly run the application on your PC.

---

## 📥 How to Download

For the program to work correctly, you need to download the **entire repository**, as the main file requires additional libraries (e.g., `libcurl.dll` and system folders) to run.

**Step 1:** At the top of this page, click on the green **`<> Code`** button.  
**Step 2:** Select **`Download ZIP`** from the drop-down menu.  
**Step 3:** Wait for the archive to finish downloading to your computer.  

---

## 📦 Extraction and Installation

1. Locate the downloaded ZIP archive (usually found in your "Downloads" folder).
2. Extract it to any convenient folder. 
   *(Right-click the archive -> select "Extract All...")*

---

## ▶️ How to Run

1. Open the folder where you just extracted the files.
2. Find the **`Meccha Upgrader.exe`** file.
3. Double-click it to launch the application.

> **⚠️ IMPORTANT:** Do not move the `Breddy.exe` file separately to your desktop! For the program to work properly, it **must always remain in the same folder** as `libcurl.dll`, `gup.xml`, and the `src`, `thirdparty`, and `tools` folders. If you need a desktop shortcut, right-click on `Breddy.exe`, select *"Create shortcut"*, and then move only the newly created shortcut to your desktop.
